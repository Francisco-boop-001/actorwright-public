# Public current-staging probes

This separate source-only profile preserves the eleven protocol-2-ready command contracts with deterministic synthetic fixtures. It does not embed an installed Skyrim master or the excluded historical workflow payloads.

The package and Full workflow materializes a verifier-owned synthetic master from the `Data/Skyrim.esm` test base and the canonical 532-byte PACK record read from the local, user-supplied `ACTORWRIGHT_TEST_SKYRIM_MASTER` file. The verifier requires one ordinary local `Skyrim.esm`, admits only the approved PACK group path, size and group-bound digest, and never writes back to the supplied file. The path is not included in reports. Missing or invalid input fails before the workflow scratch root is created.

This current profile is distinct from frozen historical probe catalogs. Historical positive Finish routes require their original authenticated payloads and report unavailable when those excluded payloads are absent; their identity, schema, and pin contracts remain unchanged.

Preview remains a pinned contract/schema check, not authentic rendering, visual approval, runtime proof, or promotion.
