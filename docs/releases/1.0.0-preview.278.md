# Actorwright 1.0.0-preview.278

Preview.278 is a private release identity. Release, candidate, promotion, and
consumer-installation status are established by their corresponding exact
artifacts and receipts, not by the source version or this note. Preview.275
remains the compatibility baseline; Preview.277 remains historical.

Preview.278 carries the Phase 3 workspace-policy shadow comparison. The
existing `KOnlyWorkspacePolicy` remains authoritative and retains its
diagnostic order, messages, refusal behavior, and permission decisions. An
independent model compares allow/refuse and ordered diagnostic codes/severity
using the same raw path observations. It does not perform a second filesystem
walk or alter user-visible results. A mismatch or observer failure cannot
change the command result.

The comparison is exposed only through the opt-in
`Actorwright-Observability` EventSource provider (keyword `8`, event ID `6`).
It records closed policy-kind and match/mismatch/failure values; it does not
write application log files or include paths, diagnostic messages, or raw
diagnostic codes. Existing dispatch, policy, and workflow events remain
unchanged. The provider stays disabled unless a local listener or runtime
collector enables it.

The product remains `PRIVATE_ONLY`. The source and package checks do not
establish Skyrim appearance, audio, animation, combat, save, or game-runtime
behavior. Candidate promotion and consumer installation remain separate
decisions supported by their own exact receipts.
