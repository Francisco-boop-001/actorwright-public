# Actorwright 1.0.0-preview.257

This private preview repairs external Hair head-part validation for presets
that use SMP hair. An HDPT's RNAM/ValidRaces field is an FLST reference; the
route now resolves that list and admits the Hair head part only when the
routed race is a member of it.

The repair preserves strict refusals for a missing or mismatched FLST
projection, deleted lists, malformed evidence, and races absent from the
resolved list. The selected Hair root is also distinguished from actual HNAM
descendants in diagnostics.

This is a compatibility repair only. It changes no command catalogue,
protocol, schema, or wire contract. The evidence is static and establishes no
runtime, visual, pathing, recruitment, consumer-install, public-release, or
promotion authority; runtime and visual authority remain false.

Preview.256 and Preview.255 remain immutable previous rollback/package/
candidate evidence.
