# Actorwright 1.0.0-preview.256

This private preview fixes captured Ruby light-plugin HDPT references whose
stored FormIDs include the light-plugin encoding. Actorwright normalizes those
references to the provider-local FormIDs before resolving the exact copied
provider record.

Ordinary provider-plugin references preserve their existing IDs and resolution
behavior. A missing normalized record, changed provider bytes, or any other
genuine plugin/record mismatch remains a strict refusal; no guessed or
basename-based fallback is admitted.

This is a compatibility repair only. It changes no command catalogue, protocol,
schema, or wire contract. The evidence is static and establishes no runtime,
visual, pathing, recruitment, consumer-install, public-release, or promotion
authority; runtime and visual authority remain false.

Preview.255 remains the immutable previous rollback/package/candidate evidence.
