# Actorwright 1.0.0-preview.277

Preview.277 remains private. Release status is bound to the exact source commit,
package bytes, and fresh compatibility evidence; this note does not substitute
for that gate. Preview.275 remains the compatibility baseline, and Preview.276
is unchanged.

Since Preview.276, release checks bind compatibility evidence to the source and
package being sealed. Frozen baseline files now retain their pinned line-ending
bytes in checkouts with Git autocrlf enabled; the pin contents are unchanged.

Phase 2 adds opt-in native EventSource observations at CLI dispatch,
K-only workspace-policy decisions, and workflow-bundle transition boundaries.
The provider is Actorwright-Observability. It is disabled by default and does
not add file logging, change the 142-command catalogue or either protocol,
replace existing journals and diagnostics, alter policy authority, or change
command output and exit behavior. These scoped events do not trace every
internal domain decision.

## Capture from the packaged CLI

The Windows CLI package is a self-contained executable. Capturing a trace uses
the runtime included with that executable; it does not require a machine-wide
.NET install, SDK, source checkout, or an installed collector. Set the package
path below to the read-only installation. Choose a separate ordinary K-local
workspace that Actorwright's workspace policy admits; the example stores both
bundle extraction and trace output there.

The child PowerShell process keeps the EventPipe settings local to this run.
This safe discovery command records dispatch start/stop events. To observe a
policy or workflow boundary, replace the final command with the intended
command that exercises that boundary.

~~~powershell
pwsh -NoProfile -Command {
    $packageExe = 'K:\path\to\actorwright-1.0.0-preview.277\cli\actorwright.exe'
    $workspaceRoot = 'K:\ActorwrightRun\preview277'
    $traceRoot = Join-Path $workspaceRoot 'traces'
    $extractRoot = Join-Path $workspaceRoot 'bundle-extract'

    if (-not (Test-Path -LiteralPath $packageExe -PathType Leaf)) {
        throw "Packaged CLI not found: $packageExe"
    }
    New-Item -ItemType Directory -Force -Path $traceRoot, $extractRoot | Out-Null

    $env:ACTORWRIGHT_WORKSPACE_ROOT = $workspaceRoot
    $env:DOTNET_BUNDLE_EXTRACT_BASE_DIR = $extractRoot
    $env:DOTNET_EnableEventPipe = '1'
    $env:DOTNET_EventPipeConfig = 'Actorwright-Observability:7:4'
    $env:DOTNET_EventPipeCircularMB = '10'
    $env:DOTNET_EventPipeOutputStreaming = '0'
    $env:DOTNET_EventPipeOutputPath = Join-Path $traceRoot 'actorwright-{pid}.nettrace'

    & $packageExe version --json
    exit $LASTEXITCODE
}
~~~

The provider emits Event IDs 1–5 for dispatch start, dispatch stop, dispatch
fault, policy decision, and workflow outcome. Keyword mask 7 enables dispatch
(1), policy (2), and workflow (4) events at Informational level (4). The
buffer value 10 is hexadecimal, or 16 MiB. The trace is written by EventPipe,
not by Actorwright's operation journal.

Event payloads use closed route, decision, reason, phase, outcome, and failure
values plus the canonical command name where applicable. They omit raw
arguments, paths, request digests, user-supplied correlation values, diagnostic
messages, NPC or reviewer identity, and exception text. The trace container
may still include process and runtime metadata, so inspect it before sharing.
This diagnostic stream is not a complete or tamper-proof audit log. See
Microsoft's [EventPipe documentation](https://learn.microsoft.com/dotnet/core/diagnostics/eventpipe)
for runtime collection details.
