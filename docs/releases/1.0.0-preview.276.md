# Actorwright 1.0.0-preview.276

This private release line contains the compatibility firewall. It preserves all
142 commands, including six voice/dialogue commands, and the eleven commands
advertised as protocol-2-ready. Existing successful NPC creation remains part
of the supported command surface.

The Source, Package, and Full gates check command catalogues, exercised
journeys, package identity, voice/dialogue routes, and release evidence before
any candidate publication. One upfront approval authorizes the bounded work;
the application does not introduce approval prompts between commands. Existing
human review required by Finish packaging remains in place.

The exact verified package and candidate determine release status. This note
grants no promotion or consumer-install authority. `runtimeAuthority` and
`visualAuthority` remain `false`; static and fixture verification does not
prove game runtime behavior, visual acceptance, voice likeness, or listening
quality.

Preview.275 is the tagged, approved, active consumer installation at 142 commands
and 317 expected Python passes. Preview.274 is the retained rollback at 142
commands and 317 expected Python passes. The Preview.276 verifier targets 880
Python passes and the current eleven-ready schema inventory; the final canonical
build must confirm 880 passed and four skipped (884 collected) before release.
The four K: environment skips are the alternate data stream, symlink alias,
and two junction fixtures. A collect-only count cannot establish skip outcomes.
