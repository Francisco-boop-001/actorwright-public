# Actorwright 1.0.0-preview.266

This private preview corrects release-test accounting after the immutable
Preview.265 tag failed its final-verifier checkpoint. Package staging,
dependency vulnerability scanning, and SBOM generation passed, but the final
summary was rejected: the builder truthfully extracted 231 passed cases from
pytest output while the Preview.265 verifier identity incorrectly expected all
234 collected cases, including three skips. No final release root or ZIP was
created, and Preview.265 was never candidate-published or promoted.

Preview.266 preserves the builder contract: `standalonePythonCases` is the
pytest passed count. The current expectation is therefore 231 passed, with
three separately skipped cases and 234 total collected. Strict selected-release
dispatch and the workspace preflight reviewed-intake rule extend through the
current identity without weakening their schema checks.

Protocol 1 retains all 136 command names and complete scoped discovery
contracts. Protocol 2 remains callable for exactly eight commands: its three
discovery kernel commands and five established workflow commands. The release
retains the same five current workflow probes.

This private release grants no game-runtime, visual, pathing, recruitment,
consumer-install, or public-release authority. Runtime and visual authority
remain false and require their separate evidence gates.

Preview.266 is frozen at this eight-command protocol-2 contract. Later source
work uses the distinct `1.0.0-preview.267` / `preview.267-private` identity.
