# Actorwright 1.0.0-preview.255

This private preview adds external SMP hair support for RaceMenu/High Poly
Head presets. Its source identity is `1.0.0-preview.255`, source line
`preview.255-private`, and expected annotated release tag
`v1.0.0-preview.255`.

Selected SMP hair remains external to the Actorwright FaceGeom carrier and
package. The output ESP retains the provider master and PNAM references so the
game-facing dependency remains explicit. Provider hair meshes, colliders,
physics XML, textures, plugin records, and other provider assets are not copied
or redistributed by Actorwright.

The release gate performs strict static prepublication verification by
reopening the provider/plugin bytes, selected dependency manifest, output
masters and PNAM references, and FaceGeom exclusion evidence. This is static
packaging evidence only; it establishes no runtime, visual, pathing,
recruitment, consumer-install, public-release, or promotion authority.

Preview.254 remains the immutable private rollback identity. No package,
candidate, promotion, consumer activation, runtime result, or visual
acceptance is implied until those separate gates pass.
