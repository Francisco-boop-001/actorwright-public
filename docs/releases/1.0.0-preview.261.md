# Actorwright 1.0.0-preview.261

Preview.261 is an immutable failed pre-release checkpoint. Its local tag was
created before corrected reviewed-intake readiness expectations were committed,
so it was never packaged, published as an Exchange candidate, or promoted.
The tag remains unchanged as historical evidence; Preview.263 is the current
private source identity and Preview.262 is a later immutable failed checkpoint.

This private preview restores the complete protocol-1 compatibility and
discovery surface without changing the frozen 136-command catalogue. All 136
protocol-1 commands now expose command-scoped, typed contracts suitable for
agent planning, including their options, aliases, relationships, artifacts,
effects, authority limits, and retry semantics.

Protocol 2 remains callable for exactly eight commands: its three discovery
kernel commands and five established workflow commands. Commands that are
discoverable as legacy are not advertised as protocol-2 callable. Preview.260
remains an admitted immutable rollback identity with its historical protocol-2
catalogue and exact 224-case standalone Python verification expectation.

The release retains the exact 136-command compatibility gate and the current
225-case standalone Python release expectation. It does not change legacy
command parsing, handlers, result behavior, or wire/schema identifiers.

This private release grants no game-runtime, visual, pathing, recruitment,
consumer-install, or public-release authority. Runtime and visual authority
remain false and require their separate evidence gates.
