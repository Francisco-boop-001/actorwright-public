136-command protocol-1 catalogue, and eleven protocol-2-ready commands.

and release assembly reached final verification, where the verifier refused
the schema-export snapshot because it omitted the truthful `pathConventions`

`pathConventions` object for the current and preserved compatible previews.

declared platform skips.
