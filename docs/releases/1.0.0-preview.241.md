# Actorwright 1.0.0-preview.241

This private preview repairs a general Finish Core source-package defect while preserving the established request and proposal schema identifiers and the exact 136-command catalogue.

`npc finish analyze` now binds the requested source plugin to exactly one `kind=plugin` package-manifest artifact at the plugin's normalized package-relative path. Product-generated layouts such as `Data/Example.esp` are accepted without weakening the match to a filename, substring, or mod-specific convention. FaceGen paths that contain the plugin name as a directory cannot become plugin candidates.

`schema export --command "npc finish analyze"` now documents that source and provider paths are relative to the configured workspace root, that the manifest is directly inside the full package root, and that plugin/provider paths remain inside that package. Provider entries publish all four runtime-required bindings as non-null, require a positive byte length, and require at least one provider. An empty provider set now returns `finish-core-authority-provider-empty` instead of the misleading duplicate-provider diagnostic.

The release remains private and binary-only. `runtimeAuthority=false` and `visualAuthority=false`; this release makes no Skyrim runtime, game-behavior, or visual-authority claim. Public distribution remains blocked by `docs/security/public-release-gate.md`.
