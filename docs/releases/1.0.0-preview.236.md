# Actorwright 1.0.0-preview.236

This is a bounded renderer repair candidate. It restores the complete embedded NPC preview renderer that preview.235 accidentally shipped with 469 lines replaced by a truncation placeholder. It also adds a pre-package test that compiles every embedded Python renderer and requires duplicated runtime and canonical tools sources to be byte-identical.

The candidate retains the 136-command CLI contract and all five preview.235 consumer-contract repairs. Blender process evidence remains bounded and failure-only.

The release is binary-only. Blender helpers are embedded resources; no runtime Python source is shipped. The package includes exchange schemas, user documentation, licenses/notices, an SPDX 2.3 dependency inventory, test evidence, and sorted SHA-256 verification.

This source repair does not itself prove rendered pixels or Skyrim behavior. `runtimeAuthority=false` and `visualAuthority=false`; consumer reruns must supply new visual and runtime evidence. Public distribution remains blocked by `docs/security/public-release-gate.md`.
