# Actorwright 1.0.0-preview.242

This private preview repairs the Finish Core apply binding reported in `NPCM-20260812-0002` while preserving the established request and proposal schema identifiers and the exact 136-command catalogue.

`npc finish apply` now accepts any schema-valid request whose supplied SHA-256 matches the exact request-file bytes already verified by the CLI and bound into the reviewed proposal. Apply no longer rejects valid noncanonical JSON by recomputing a different hash from its parsed typed model. The exact raw-file hash, proposal self-hash, proposal-to-request binding, fresh source reinspection, and fresh proposal derivation gates remain enforced.

Successful Actor Assembly inspection still admits a null optional `authorities.actorAssemblySha256`. The request contract now closes `followerPolicy.defensiveOnly` to `true` in both runtime validation and exported JSON Schema, matching the writer's existing zero-offense defensive combat style.

The broader schema-driven `validate-all` convenience command remains deferred; this release repairs only the proven Finish Core blockers.

The release remains private and binary-only. `runtimeAuthority=false` and `visualAuthority=false`; this release makes no Skyrim runtime, game-behavior, or visual-authority claim. Public distribution remains blocked by `docs/security/public-release-gate.md`.
