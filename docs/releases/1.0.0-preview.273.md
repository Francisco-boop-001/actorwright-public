# Actorwright 1.0.0-preview.273

This private release line contains the NPC and voice integration repairs.
Its release evidence and exact-hash Exchange candidate determine packaging and
publication status; this note grants no promotion or consumer-install authority.
It makes no listening-quality, voice-likeness, visual, game-runtime, or
public-release claim.

The current source reports `preview.273-private` and 142 protocol-1 commands.
The eleven-command protocol-2-ready set is unchanged. Six new protocol-1
commands cover local XTTS discovery, authorized reference WAV import,
resumable synthesis, and hash-bound dialogue-overlay analyze/apply/verify.
Actorwright does not embed, install, start, or administer XTTS.

The Voice panel offers editable endpoint/platform/server-folder/output-folder
setup with Check and Check and save. Workspace-local settings are shared with
the noninteractive CLI. Native Windows Mantella discovery and sample paths are
supported; valid 24 kHz mono float32 responses are converted to PCM16 while
preserving the output silence checks. Three real test-only lines and unchanged
resume were verified against a native Windows server; no NPC voice assignment
or subjective audio-quality claim follows from that test.

Dialogue analysis is deliberately bounded. It refuses a source plugin that
already owns `INFO` records with `dialogue-source-dialogue-unsupported` because
inherited dialogue and audio import are unsupported. It binds the strict copied
master closure and the selected source SEQ path/hash, or exact absence;
plugin-adjacent SEQ bytes take precedence over a copied Data-root SEQ. Extra
plugins may remain in the reviewed load order without becoming masters or
resolving conditions unless the analyzed plan names them.

Apply produces an overlay containing the rewritten plugin, new voice assets,
the shared PEX, and preserved plus appended SEQ data. The original NPC package
is still required for FaceGen, skin, and other inherited assets. External LIP
tools are optional inputs and remain independently installed.

The current canonical Python inventory contains 319 cases: 316 expected passes
and three declared platform skips. The tagged Preview.272 package and its
verifier profile remain immutable at 136 commands and 315 expected Python
passes plus three skips. Preview.273 current-staging schemas additionally expose
the implemented `npc create-from-jslot` `output.pluginType` field without
rewriting the Preview.272 schema snapshot.
