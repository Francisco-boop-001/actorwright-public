# Actorwright 1.0.0-preview.270

This private release candidate preserves Preview.269 product behavior and its
136-command protocol-1 catalogue plus eleven protocol-2-ready commands.

Previews 267 through 269 remain immutable failed release-builder checkpoints.
Preview.270 opens vulnerability-report directory leases with the minimum
directory-list access and read/write sharing while deliberately withholding
delete sharing. This lets the scanner coexist with ordinary live repository
handles while continuing to block output-parent rename, deletion, and reparse
swaps through the final create-new write.

The regression covers both properties: an ordinary non-delete-shared handle
can coexist with the scanner, and a held scanner lease still refuses parent
replacement. A package, Exchange candidate, promotion, consumer installation,
or public release requires its separate evidence and approval gates. Runtime
and visual authority remain false.
