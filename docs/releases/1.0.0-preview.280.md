# Actorwright 1.0.0-preview.280

`99a1acc15695350e8e4fb040a2053adc851e8030`, with local annotated tag
`v1.0.0-preview.280`. The release was integrated into local `main`; there was no
remote push or tag publication. Preview.279 is the immediate rollback, and
