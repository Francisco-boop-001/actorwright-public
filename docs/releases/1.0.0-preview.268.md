# Actorwright 1.0.0-preview.268

This private release candidate preserves Preview.267 product behavior and its
136-command protocol-1 catalogue plus eleven protocol-2-ready commands.

Preview.267 remains an immutable failed release-builder checkpoint: Windows
PowerShell treated a harmless native stderr diagnostic as terminating before
the builder could inspect the child exit code. The same source passed the
separate canonical gate. Preview.268 repairs that release-only process boundary
and adds an executable regression for both successful and failing child exit
codes.

A package, Exchange candidate, promotion, consumer installation, or public
release requires its separate evidence and approval gates. Runtime and visual
authority remain false.
