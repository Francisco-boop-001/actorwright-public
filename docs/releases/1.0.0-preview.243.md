# Actorwright 1.0.0-preview.243

This private preview closes the consolidated follower-authoring request `NPCM-20260812-0004` without changing the established Finish Core request/proposal schema identifiers or the exact 136-command catalogue.

Finish Core transactions now preserve the admitted package-relative plugin path produced by Actorwright packages, including `Data/<plugin>.esp`. Apply, independent verification, package-tree hashing, and direct-install archive projection use that same exact relative identity. Source package evidence remains immutable, and archives refuse duplicate or `Data/Data/` projections.

The optional closed `aiPolicy` request member can author all five Skyrim NPC `AIDT` follower fields: aggression, confidence, energy, morality, and assistance. Omitting it preserves source `AIDT` bytes. A recruitable actor whose effective assistance remains `HelpsNobody` is refused. The independent typed/raw verifier requires exact policy readback.

`npc patch` now binds the consumer spelling `--input-sha`, canonical `--input-sha256`, and legacy `--expected-sha256`; simultaneous aliases must agree. Schema export publishes the exact hash-bound proposal document instead of returning an empty document-schema list.

`npc finish analyze` and `npc finish apply` accept `--validate-all`. This phase-aware mode accumulates safely reachable diagnostics, explicitly marks dependency-skipped phases, and exercises valid requests through disposable writer, verifier, package hashing, and archive readback. It creates none of the requested proposal, output package, or archive and removes its private staging before return.

The release remains private and binary-only. `runtimeAuthority=false` and `visualAuthority=false`; static verification does not establish Skyrim runtime, follower behavior, or visual authority. Public distribution remains blocked by `docs/security/public-release-gate.md`.
