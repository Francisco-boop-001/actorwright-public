# Actorwright 1.0.0-preview.269

This private release candidate preserves Preview.268 product behavior and its
136-command protocol-1 catalogue plus eleven protocol-2-ready commands.

Preview.267 and Preview.268 remain immutable failed release-builder
checkpoints. Preview.269 captures native child output as plain strings,
normalizes it to LF before parsing evidence stamps, and still uses the saved
child exit code as the success boundary. The executable regression covers
native stderr with both zero and nonzero exits and requires an uncorrupted
machine-readable evidence stream.

A package, Exchange candidate, promotion, consumer installation, or public
release requires its separate evidence and approval gates. Runtime and visual
authority remain false.
