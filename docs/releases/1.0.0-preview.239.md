# Actorwright 1.0.0-preview.239

This private preview preserves the complete `v1.0.0-preview.238` ancestry and its Finish Core schema, renderer, provider-migration, and producer-to-consumer behavior.

It adds the reviewed product and handoff governance plus four bounded-readiness repairs: exact-parent workspace containment is refused; MediaPipe disposal is atomic and nonblocking; CLI diagnostic exits use one exact 369-code security registry across the 100 release-lineage handlers; and desktop startup, initialization, and crash wiring fail through explicit bounded surfaces without preventing optional-feature degradation.

The command catalogue remains exactly 136 unique commands. Finish Core analyze/apply document schemas, closed-member and admitted-enum diagnostics, embedded renderer authority, process evidence, and product-provider closure remain pinned by preservation tests.

The release remains private and binary-only. `runtimeAuthority=false` and `visualAuthority=false`; this release makes no Skyrim runtime, game-behavior, or visual-authority claim. Public distribution remains blocked by `docs/security/public-release-gate.md`.
