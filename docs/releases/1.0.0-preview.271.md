# Actorwright 1.0.0-preview.271

This private release candidate preserves Preview.270 product behavior, its
136-command protocol-1 catalogue, and eleven protocol-2-ready commands.

Preview.270 remains an immutable unpublished checkpoint. Its exact source tree
passed the canonical gate and binary staging, but the release builder omitted
the reviewed NuGet configuration from the vulnerability scan. The scan then
attempted unavailable direct network access and correctly stopped publication
with `NETWORK_REQUIRED`.

Preview.271 carries the exact reviewed restore configuration through the build,
restore, and vulnerable-package query. When that configuration uses a local
transport for an authenticated copy of the official NuGet advisory feed, the
report preserves the raw loopback source and binds the configuration hash plus
the fetched upstream URLs, sizes, hashes, timestamp, and verified TLS method.
The release verifier cross-checks that configuration hash against the sealed
canonical-build log.

A package, Exchange candidate, promotion, consumer installation, or public
release still requires its separate evidence and approval gates. Runtime and
visual authority remain false.
