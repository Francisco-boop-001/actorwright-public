# Actorwright 1.0.0-preview.252

This private preview records the reviewed Aelva repair set. Its exact source
identity is `1.0.0-preview.252`, source line `preview.252-private`, and
annotated release tag `v1.0.0-preview.252`. The tag binds source identity only;
package, candidate, and private-promotion gates remain pending.

The reviewed repairs are deliberately limited to these Aelva findings:

- Exposure evidence with finite nonzero underexposure is advisory; missing,
  empty, or nonfinite required mask/luminance evidence remains fail-closed.
- `schema export --command "npc create-from-jslot"` now exposes the closed
  `npc.create-from-jslot.request.v1` input document schema so agents can use
  the source-owned contract instead of reverse-engineering request JSON.
- Reviewed-intake diagnostics distinguish a missing output-root parent from a
  colliding output path. The intake output root is reserved and the later
  package request must use a different fresh output root.
- Malformed external and selected headpart NIF diagnostics identify the
  logical admitted source path, making the refusal actionable without changing
  the binary-reader boundary.
- The consumer handoff now directs agents to discover the request schema,
  preserve the intake output root, create distinct fresh outputs, and inspect
  the body-skin authority route before treating a body as packaged.

The exact 136-command protocol-v1 catalogue and the nine existing protocol-v2
ready commands are unchanged. This static source/documentation evidence does
not establish runtime, visual, pathing, recruitment, consumer-install,
promotion, or public-release authority. External renderer prerequisites remain
user-owned and are not bundled. Preview.251 and Preview.250 remain immutable
rollback identities; no preview.252 package, candidate, private promotion,
consumer activation, runtime result, or visual acceptance is implied until its
later release gates complete.
