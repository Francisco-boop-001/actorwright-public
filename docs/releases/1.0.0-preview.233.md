# Actorwright 1.0.0-preview.233

This is the first private Actorwright repository release reconstructed from the exact preserved preview.231 product-source line. It keeps the 136-command CLI contract, makes `actorwright.exe` the primary entry point, retains `npcm.cmd` as a compatibility launcher, and includes the supported desktop application.

The release is binary-only. Blender helpers are embedded resources; no runtime Python source is shipped. The package includes exchange schemas, user documentation, licenses/notices, an SPDX 2.3 dependency inventory, test evidence, and sorted SHA-256 verification.

This is private static/off-engine tooling. `runtimeAuthority=false` and `visualAuthority=false`; Skyrim NPC outputs still require their own mod-workspace and in-game gates. Public distribution remains blocked by `docs/security/public-release-gate.md`.
