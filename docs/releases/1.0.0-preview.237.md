# Actorwright 1.0.0-preview.237

This is a bounded renderer-authority repair candidate. It replaces four copied NPC-preview renderer hashes with one product authority shared by CLI and Desktop composition, then verifies that authority against the embedded script bytes.

Hash-refusal diagnostics now report both the admitted and observed SHA-256 values. Release verification still compiles every embedded Python renderer before packaging, retains the 136-command CLI contract, and preserves the preview.235 consumer-contract repairs and preview.236 renderer restoration.

The release is binary-only. Blender helpers are embedded resources; no runtime Python source is shipped. The package includes exchange schemas, user documentation, licenses/notices, an SPDX 2.3 dependency inventory, test evidence, and sorted SHA-256 verification.

This repair admits the restored renderer to reach Blender; it does not itself prove rendered pixels or Skyrim behavior. `runtimeAuthority=false` and `visualAuthority=false`; consumer reruns must supply new visual and runtime evidence. Public distribution remains blocked by `docs/security/public-release-gate.md`.
