# Actorwright 1.0.0-preview.238

This private preview repairs the hash-bound Finish Core authoring contract reported in `NPCM-20260810-0006`.

`schema export --command "npc finish analyze"` now embeds draft-2020-12 request and proposal JSON Schemas. The request schema publishes the nine closed top-level members and the exact case-sensitive body-route, outfit-policy, and inventory-policy enum sets; the proposal schema publishes its closed status set. `npc finish apply` publishes the same request and proposal schemas as inputs. Other commands expose an empty `documentSchemas` array until their codecs have separately grounded contracts.

Finish Core enum refusals now list their admitted values directly. The existing member-level `unknown=[..], missing=[..]` refusal remains unchanged, and command help directs consumers to the exported document schemas.

The release remains binary-only and private. It retains the exact 136-command compatibility contract and the prior preview.237 renderer-authority repair. This change grants no Skyrim runtime or visual authority: `runtimeAuthority=false` and `visualAuthority=false`. Public distribution remains blocked by `docs/security/public-release-gate.md`.
