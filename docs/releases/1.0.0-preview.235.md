# Actorwright 1.0.0-preview.235

This is a diagnostic repair candidate. It fixes manifest/intake/migration/load-order contracts and persists bounded Blender process evidence. It does not claim Skyrim runtime authority, visual authority, or restored six-view pixels.

The candidate retains the 136-command CLI contract, `actorwright.exe` as the primary entry point, `npcm.cmd` as the compatibility launcher, and the supported desktop application. It repairs exact dependency-manifest wire shapes, routes `preview npc` through the reviewed-intake codec, makes provider-migration acceptance executable, admits one leading UTF-8 BOM while hashing original load-order bytes, and persists bounded failure-only Blender process evidence.

The release is binary-only. Blender helpers are embedded resources; no runtime Python source is shipped. The package includes exchange schemas, user documentation, licenses/notices, an SPDX 2.3 dependency inventory, test evidence, and sorted SHA-256 verification.

This remains private static/off-engine tooling. `runtimeAuthority=false` and `visualAuthority=false`; consumer reruns must supply new runtime and visual evidence. Public distribution remains blocked by `docs/security/public-release-gate.md`.
