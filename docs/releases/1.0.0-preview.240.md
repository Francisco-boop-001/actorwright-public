# Actorwright 1.0.0-preview.240

This private preview repairs Finish Core authority discovery for source packages while preserving the established request and proposal schema identifiers and the exact 136-command catalogue.

`schema export --command "npc finish analyze"` now marks every source and actor binding that analyze already requires as non-null and publishes the exact ordinal package-tree SHA-256 derivation. The three independent evidence hashes remain nullable when their corresponding evidence is absent.

Finish Core refusals now list the exact missing source or actor bindings. A package-tree mismatch reports both the computed expected SHA-256 and the received request binding, so a producer can construct a valid request without guessing the tree algorithm.

The release remains private and binary-only. `runtimeAuthority=false` and `visualAuthority=false`; this release makes no Skyrim runtime, game-behavior, or visual-authority claim. Public distribution remains blocked by `docs/security/public-release-gate.md`.
