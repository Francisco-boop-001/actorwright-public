# Actorwright 1.0.0-preview.251

This private preview advances the agent-first Skyrim workflow while preserving
the frozen 136-command protocol-v1 catalogue. The source/package identity is
`1.0.0-preview.251`, source line `preview.251-private`, and immutable local
tag `v1.0.0-preview.251`. The tag binds source identity only; package,
candidate, and private-promotion gates remain pending.

The protocol-v2 contract is closed around the six implemented ready workflow
names:

```text
npc assembly preflight
npc create-from-jslot
npc finish verify
preset inspect
preview npc
workspace preflight
```

`gui`, `npc finish analyze`, and `npc finish apply` remain catalogued
protocol-1 commands with `Legacy` readiness and no advertised protocol-v2
result schemas. Their GUI/Finish migration is a separately deferred surface,
not a preview.251 readiness claim.

The discovery kernel remains `capabilities`, `version`, and `schema export`.
Every advertised result and document schema must be exported from the
source-owned catalog exactly once, and every ready adapter diagnostic must be
present in the central diagnostic vocabulary and local operation journal.

The workflow is intentionally branchable: an appearance-only build and
off-engine preview can be a successful resumable stopping point. The currently
advertised workflow receipts bind the exact package, preview, request, and
proposal bytes for the implemented preflight/create/preview and Finish Verify
surfaces. Finish Analyze and Finish Apply remain Legacy/unadvertised, and
their human-receipt overlay is outside this preview. Static evidence never
establishes human visual acceptance, Skyrim runtime behavior, promotion
approval, or public release authority.

The Aelva integration findings have two named source/build root causes. First,
nested preset/preview dictionaries (body morphs, keyed morphs, transforms,
skin overrides, and head-part data) did not preserve a canonical member order
across typed round trips; preview.251's owned dictionary writer orders those
members ordinally while preserving the contract order of arrays and the exact
string/value representation. The workflow request digest likewise
canonicalizes only its declared transport and option-order rules. Other
protocol, package, and release manifests are not covered by a global sorted-key
rule: they remain exact serialized bytes bound by their recorded SHA-256
values. Second, the effect vocabulary and terminal journaling were split
between adapters and the runner; preview.251 uses the shared effect
kind/status/scope vocabulary and records the attempted and terminal
local-journal effects in the same envelope that is verified.

The issue-closure corrections are explicit:

- Android: malformed or bare `--plugin` and `--output` values are admitted by
  typed workspace-path checks before request construction; the existing JSON
  array and comma-separated `--items` syntax remains ordered and compatible.
  AIDT/mood and external-master authority route through Finish Core, where
  schema-2 masters require an explicit plugin path, uppercase physical SHA-256,
  byte length, and load-order index; omitted AI policy preserves source bytes.
- Rogue: Finish Analyze, Apply, and Verify share the pure external-master
  planner and compare its exact result with TES4 masters. Filename/FormID-only
  identity and identity-only `records propose` artifacts are refused, and every
  exact-one incompatibility reports the identity, expected count `1`, and
  observed count before any plugin write.
- Actor Assembly: `npc assembly preflight` admits only the hash-bound contract
  and fresh output beneath the K-local workspace, exports the contract/result/
  error document schemas, persists and reopens one typed result, and emits no
  runtime, visual, or promotion authority. The invalid-contract probe remains
  a deterministic typed refusal with no artifact.
- TRI: anonymous or multi-shape morphs require an explicit hash-bound source
  map; no filename, INI, sibling, or likely-slider inference is allowed. Each
  exact target shape is checked for topology/count and receives before/after
  vertex hashes; structured Blender status remains authoritative even on a
  nonzero process exit, while legacy `--morphs` stays schema-1 compatible.

External Blender, PyNifly, Texconv, and other renderer/tool prerequisites
remain official user-owned installations; they are not bundled or redistributed
by this package. The binary-only consumer must validate copied mod inputs and
return its independent six-view preview evidence.

Preview.250 remains the private rollback identity at
`v1.0.0-preview.250`. Its release document, tag, candidate, and consumer
evidence are historical and must not be overwritten. The immutable local
preview.251 tag exists, but no preview.251 package, candidate, private
promotion, consumer activation, runtime result, or visual acceptance is
implied until its later release gates complete.
